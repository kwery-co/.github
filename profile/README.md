## kwery

One API for product and price data from European marketplaces and price comparison sites.

Send a GTIN, a product ID or a search term. Get back the product, every seller offer, prices
with shipping, and where and when each price was seen, in the same JSON shape for every source.

**Sources:** Amazon, Google Shopping, eBay, idealo, Kaufland, Otto, billiger.de, Guenstiger,
Lidl, Walmart, Rakuten, AliExpress. [Countries and fields per source →](https://docs.kwery.co/sources)
